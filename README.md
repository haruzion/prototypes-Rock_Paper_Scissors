# prototypes-Rock_Paper_Scissors

じゃんけんゲーム (Rock Paper Scissors Game)

## 概要 (Overview)

シンプルなHTML/CSS/JavaScriptで作成されたじゃんけんゲームです。
A simple Rock Paper Scissors game created with HTML, CSS, and JavaScript.

## 機能 (Features)

- 💎 グー、パー、チョキの3つの選択肢 (Rock, Paper, Scissors choices)
- 📊 スコアボード (Score tracking)
- 🎨 レスポンシブデザイン (Responsive design)
- 🔄 リセット機能 (Reset functionality)
- 🎭 アニメーション効果 (Animated results)

## 使い方 (How to Use)

1. `index.html` をブラウザで開く (Open `index.html` in your browser)
2. グー、パー、チョキのいずれかをクリック (Click Rock, Paper, or Scissors)
3. コンピューターと対戦 (Play against the computer)
4. スコアをリセットする場合は「リセット」ボタンをクリック (Click "Reset" to reset the score)

## ファイル構成 (File Structure)

```
├── index.html    # メインHTMLファイル (Main HTML file)
├── styles.css    # スタイルシート (Stylesheet)
└── script.js     # ゲームロジック (Game logic)
```

## ゲームルール (Game Rules)

- ✊ グー（Rock）は ✌️ チョキ（Scissors）に勝つ
- ✋ パー（Paper）は ✊ グー（Rock）に勝つ
- ✌️ チョキ（Scissors）は ✋ パー（Paper）に勝つ
